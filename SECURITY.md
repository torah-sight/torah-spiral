# Security Policy

**Languages:** **English** · [Русский](SECURITY.ru.md) · [עברית](SECURITY.he.md)

Torah Spiral is a static single page with no server, no accounts and no data collection. Preferences are
kept only in the browser's `localStorage`.

## Supported versions

Only the latest version on the `main` branch, as deployed to GitHub Pages, is supported.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on the repository page.

Include what you found, how to reproduce it, and what impact you expect. You will get an answer as soon
as the maintainers can review it.
