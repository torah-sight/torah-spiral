# Как помочь «Спирали Торы»

**Языки:** [English](CONTRIBUTING.md) · **Русский** · [עברית](CONTRIBUTING.he.md)

Спасибо за помощь. Рады вкладу любого размера: опечатка в сюжете, более точная ключевая фраза,
исправление ошибки, правка перевода, новая идея для игры.

## Основные правила

- Будьте добры. См. [Кодекс поведения](CODE_OF_CONDUCT.ru.md).
- Внося вклад, вы соглашаетесь, что ваша работа распространяется по лицензии [GPL-3.0-only](LICENSE).
- О проблемах безопасности сообщают закрыто, а не в открытых issues. См. [SECURITY.ru.md](SECURITY.ru.md).

## С чего начать

Нужен Node.js 24 или новее.

```sh
npm ci
npm run dev
```

Перед pull request запустите те же проверки, что и CI:

```sh
npm run lint
npm run typecheck
npm test
npm run docs:check
npm run content:check
npm run build
```

`npm run content:check` и `npm run density` один раз скачивают ивритский текст с Sefaria и кэшируют
его в `.cache/` (Git его игнорирует). Текст никогда не коммитится и не попадает в `dist/`.

## Правила кода

- Архитектура — по [React Carburetor](https://github.com/PHPCraftdream/ReactCarburetor): сторы с
  мутаторами на уровне модуля, компоненты `ScopedAntiHookComponent`, токены и scope. Включены все 54
  правила линтера Carburetor, включая правила функциональных классов; пожалуйста, не отключайте их.
- Не больше 500 строк в файле кода и не больше 7 элементов в папке в `src`, `scripts`, `tests` и
  `.github` (`scripts/repo/checkStructure.ts`).
- Импорты внутри проекта — через `#src/*`.
- Стили — функциональные классы: элемент несёт один класс, который называет, что он делает (`topbar-panel`,
  `parsha-cell`). Этажи Palette → Role → Tone и Brick → Trait → Pattern → Function лежат в
  `src/shell/classes`, их проверяет `npm run lint`. В разметке нет утилит Tailwind и нет вариантов `dark:`:
  тёмная тема переопределяет Roles под `[data-theme="dark"]`.
- Каждая строка, которую видит пользователь, идёт через `src/i18n` и есть на иврите, русском и английском.
- Комментарии в коде — короткие.

## Документы

README, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY и шаблон pull request есть на английском, русском и
иврите. Их собирает [polydoc](https://github.com/ktav-lang/polydoc) из `root-docs/` (шаблон pull request —
из `docs/root-docs/`). Правьте исходные юниты `root-docs/<DOC>/<unit>/body-1.md`, где все языки лежат
в одном файле, каждый после своей строки `>>>>> lang=`, затем запустите `npm run docs`. Сгенерированные
файлы `*.md` руками не правят: CI запускает `npm run docs:check`.

## Правила содержания

Содержание лежит в `src/content/books/*.ts`: имена, ключевые фразы и краткий сюжет каждой из 54
недельных глав на трёх языках.

- Каждое ивритское имя и каждая фраза должны встречаться в тексте своей главы. Это проверяет
  `npm run content:check`.
- Выбирайте то, что отличает главу, а не то, что в ней просто есть.
- Предложение сюжета должно быть понятно само по себе: игра показывает предложения по одному.
- Если сомневаетесь в толковании, сначала откройте issue по шаблону «Content error».

## Pull requests

- Одна тема на один pull request.
- Опишите, что изменилось и зачем; дайте ссылку на issue, если он есть.
- Для изменений интерфейса помогают скриншоты (светлая и тёмная тема и RTL для иврита).
