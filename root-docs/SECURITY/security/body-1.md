# Security Policy

**Languages:** **English** · [Русский](SECURITY.ru.md) · [עברית](SECURITY.he.md)

Torah Spiral is a static single page with no server, no accounts and no data collection. Preferences are
kept only in the browser's `localStorage`.

## Supported versions

Only the latest version on the `main` branch, as deployed to GitHub Pages, is supported.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on the repository page.

Include what you found, how to reproduce it, and what impact you expect. You will get an answer as soon
as the maintainers can review it.

# Политика безопасности

**Языки:** [English](SECURITY.md) · **Русский** · [עברית](SECURITY.he.md)

«Спираль Торы» — статическая страница без сервера, без учётных записей и без сбора данных. Настройки
хранятся только в `localStorage` браузера.

## Поддерживаемые версии

Поддерживается только последняя версия в ветке `main`, выложенная на GitHub Pages.

## Как сообщить об уязвимости

Пожалуйста, не открывайте публичный issue. Используйте закрытое сообщение GitHub:
**Security → Report a vulnerability** на странице репозитория.

Опишите, что нашли, как это воспроизвести и какое влияние ожидаете. Ответ придёт, как только
сопровождающие смогут это рассмотреть.

# מדיניות אבטחה

**שפות:** [English](SECURITY.md) · [Русский](SECURITY.ru.md) · **עברית**

ספירלת התורה היא עמוד סטטי אחד, בלי שרת, בלי חשבונות משתמש ובלי איסוף נתונים. ההעדפות נשמרות רק
ב־`localStorage` של הדפדפן.

## גרסאות נתמכות

נתמכת רק הגרסה האחרונה בענף `main`, כפי שהיא מוצבת ב־GitHub Pages.

## דיווח על פגיעות

נא לא לפתוח issue פומבי. השתמשו בדיווח הפרטי של GitHub:
**Security → Report a vulnerability** בעמוד המאגר.

כתבו מה מצאתם, איך לשחזר זאת ואיזו השפעה אתם צופים. תקבלו תשובה ברגע שהמתחזקים יוכלו לבדוק.
