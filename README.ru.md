# Спираль Торы · ספירלת התורה · Torah Spiral

**Языки:** [English](README.md) · **Русский** · [עברית](README.he.md)

[![CI](https://github.com/torah-sight/torah-spiral/actions/workflows/ci.yml/badge.svg)](https://github.com/torah-sight/torah-spiral/actions/workflows/ci.yml)
[![License: GPL-3.0](https://img.shields.io/badge/license-GPL--3.0-blue.svg)](LICENSE)

**Сайт:** https://torah-sight.github.io/torah-spiral/ru/ · интерфейс на иврите ([/he/](https://torah-sight.github.io/torah-spiral/he/)), русском ([/ru/](https://torah-sight.github.io/torah-spiral/ru/)) и
английском ([/en/](https://torah-sight.github.io/torah-spiral/en/)); языковая ссылка открывает сайт сразу на этом языке.

Статическое одностраничное приложение для изучения Торы по спирали, как таблицы умножения: таблица 6 × 9
(или пять столбцов-книг) из 54 недельных глав, со слоями, которые включаются по выбору, — названия, ключевые
имена, ключевые фразы, очень краткий сюжет. Ёмкость каждого уровня пропорциональна плотности главы: числу
её слов **после схлопывания повторов** (дословных, как приношения двенадцати князей, и пересказов, как
рассказ Элиэзера или Ваякхель–Пкудей).

Сделано на [React Carburetor](https://github.com/PHPCraftdream/ReactCarburetor) 0.2.0, Rsbuild (Rspack),
TypeScript (tsgo) и Tailwind CSS. Результат сборки — один самодостаточный `dist/index.html` и его копии
для языковых ссылок (`dist/he/`, `dist/ru/`, `dist/en/`).

## Возможности

- **Обзор глав** — таблица 6 × 9 или пять столбцов-книг; названия видны всегда, имена, фразы и сюжет включаются по отдельности.
- **Статистика глав** — топы глав по нестираемым Именам Всевышнего, по заповедям (Сефер а-Хинух: все,
  повелевающие, запрещающие) и по стихам, словам или буквам.
- **Игра** — найти место главы (по названию, между, перед, после) или узнать её по сюжету и уникальным
  фразам; выбор книг, отгаданные клетки остаются открытыми или прячутся, игра на время.
- Гематрия названия каждой главы.
- Светлая и тёмная тема, раскладка справа налево для иврита, работает офлайн одним файлом.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Сервер разработки |
| `npm run build` | Сборка в один файл `dist/index.html` и его языковые копии |
| `npm run lint` | oxlint (все правила React Carburetor), `carburetor-lint`, ≤ 500 строк в файле, ≤ 7 элементов в папке |
| `npm run typecheck` | `tsgo --noEmit` |
| `npm test` | Модульные тесты (rstest) |
| `npm run names` | Подсчёт нестираемых Имён Всевышнего по главам в `src/content/generated/names.json` (огласованный текст MAM с Sefaria, кэш в `.cache/`) |
| `npm run density` | Пересчёт `src/content/generated/density.json` по ивритскому тексту (Sefaria, кэш в `.cache/`) |
| `npm run content:check` | Проверка каждого ивритского имени и фразы по тексту их главы |
| `npm run docs` | Сборка документов на английском, русском и иврите из `root-docs/` ([polydoc](https://github.com/ktav-lang/polydoc)) |
| `npm run docs:check` | Проверка, что собранные документы совпадают с `root-docs/` |

## Плотность, Имена и заповеди

`src/domain/density` схлопывает повторы в три слоя: дословные 5-словные шинглы по всей Торе, строгий
общий поиск пересказов (пересечение с весами IDF в окне из 3 стихов) и выверенный список известных
пересказов (`known/knownRepeats.ts`), которые сверяются только со своим источником. Ёмкость уровня —
`rate × effective / mean effective`, не меньше 1.

Текст: Sefaria, «Tanach with Text Only» (общественное достояние). Используется только при сборке.

Имена Всевышнего: считаются только нестираемые (святые) употребления, по трактату Софрим, глава 4.
Огласованный текст «Микра по Масоре» (Sefaria, CC BY-SA, из ивритского Викитеки) отличает אֲדֹנָי от
אֲדֹנִי и אֵל от אֶל; светские употребления с тем же написанием (чужие боги, судьи, Бейт-Эль, «эти»)
перечислены с причинами в `src/content/tallies/nameFixes.ts`. Хранятся только числа.

Заповеди: по главам — по заголовкам самого Сефер а-Хинух (`src/content/tallies/mitzvot.ts`), сверены
с разметкой глав на Sefaria: 248 повелевающих и 365 запрещающих, всего 613.
