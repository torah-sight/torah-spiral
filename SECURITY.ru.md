# Политика безопасности

**Языки:** [English](SECURITY.md) · **Русский** · [עברית](SECURITY.he.md)

«Спираль Торы» — статическая страница без сервера, без учётных записей и без сбора данных. Настройки
хранятся только в `localStorage` браузера.

## Поддерживаемые версии

Поддерживается только последняя версия в ветке `main`, выложенная на GitHub Pages.

## Как сообщить об уязвимости

Пожалуйста, не открывайте публичный issue. Используйте закрытое сообщение GitHub:
**Security → Report a vulnerability** на странице репозитория.

Опишите, что нашли, как это воспроизвести и какое влияние ожидаете. Ответ придёт, как только
сопровождающие смогут это рассмотреть.
